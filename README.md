# Основы сетей мобильной связи (MCN)

Репозиторий содержит лабораторные и практические работы по дисциплине **«Основы сетей мобильной связи»**.

## Стек технологий и инструменты
Для выполнения работ может использоваться любой из следующих инструментов:
* **Python** (библиотеки `SciPy`, `NumPy`, `Matplotlib`)
* **MATLAB**
* **C/C++**
* **Audacity** (для анализа звуковых сигналов)

---

## Структура репозитория

Каждая работа находится в соответствующей директории и включает в себя исходный код (скрипты).

* `lab1/` — **Лабораторная работа №1: Временная и частотная формы сигналов. Преобразования Фурье. Дискретизация сигналов**
  * Исследование непрерывных и дискретных сигналов.
  * Применение прямого (ППФ/FFT) и обратного (ОПФ/IFFT) преобразования Фурье.
  * Проверка теоремы Котельникова (Найквиста) и изучение эффекта наложения спектров (aliasing).
  * Анализ спектра голосового сигнала (работа с `.wav` файлами и функцией `downsample`).
  * Квантование по уровню и оценка средней ошибки квантования для различной разрядности АЦП (3/4/5/6 бит).

* `lab2/` — **Лабораторная работа №2: Проектирование радиопокрытия мобильных сетей. Модели распространения сигналов. Бюджеты каналов**
  * Расчёт бюджета восходящего (UL) и нисходящего (DL) каналов связи, определение уровня максимально допустимых потерь сигнала (MAPL<sub>UL</sub> и MAPL<sub>DL</sub>).
  * Исследование моделей распространения радиосигналов: **UMINLOS** (для микросетей и indoor-сценариев), **COST 231 Hata** (для макросот) и **Walfish-Ikegami** (для городской застройки).
  * Построение зависимостей потерь радиосигнала PL(d) от расстояния d между базовой станцией (BS) и абонентским терминалом (UE).
  * Определение радиусов сот R<sub>UL</sub> и R<sub>DL</sub> по точкам пересечения кривых затухания с уровнями MAPL.
  * Расчёт площади покрытия сайта (S = 1.95 · R²) и определение требуемого количества базовых станций для макротерритории (100 км²) и indoor-покрытия (4 км²).

* `lab4/` — **Практическая работа №4: Изучение корреляционных свойств последовательностей, используемых для синхронизации в сетях мобильной связи**
  * Формирование псевдослучайных двоичных последовательностей и кодов Голда с помощью линейных регистров сдвига с обратной связью (LFSR).
  * Генерация последовательности Голда по схеме для нечётного номера группы (рис. 4.5).
  * Расчёт автокорреляционной функции исходной последовательности и взаимной корреляции двух последовательностей Голда.
  * Реализация на C/C++ и MATLAB (`xcorr`), сравнение результатов.
  * Построение графика автокорреляционной функции в зависимости от задержки (lag).
  * Анализ корреляционных свойств и их применение для временной синхронизации приёмника и передатчика.

* `lab5/` — **Практическая работа №5: Циклический избыточный код (CRC)**
  * Изучение принципов обнаружения ошибок при передаче данных в сетях мобильной связи с использованием CRC (Cyclic Redundancy Check).
  * Формирование порождающего полинома в соответствии с индивидуальным вариантом и его представление в двоичном виде.
  * Реализация алгоритма вычисления CRC на C/C++ посредством двоичного деления по модулю 2 с использованием операции XOR.
  * Формирование передаваемых пакетов с контрольной последовательностью для информационных блоков длиной 32 и 250 бит.
  * Проверка целостности принятых пакетов и моделирование ошибок в канале связи посредством инвертирования битов.
  * Исследование обнаружения накопленных ошибок путём последовательного искажения всех 257 бит передаваемого пакета.
  * Расчёт эффективности обнаружения ошибок, анализ случаев необнаруженных искажений и исследование ограничений метода CRC.

* `RGR/` — **Расчётно-графическая работа: Моделирование процесса передачи и приёма цифрового сигнала в канале связи**
  * Реализация полного цикла передачи и приёма текстового сообщения на Python с использованием библиотек `NumPy` и `Matplotlib`.
  * ASCII-кодирование исходного текстового сообщения и формирование информационной битовой последовательности.
  * Вычисление циклического избыточного кода (CRC) посредством двоичного деления по модулю 2 и формирование пакета с контрольной последовательностью.
  * Генерация последовательности Голда с помощью линейных регистров сдвига с обратной связью (LFSR) и её использование в качестве синхросигнала.
  * Формирование дискретного сигнала во временной области с заданным количеством отсчётов на бит и частотой дискретизации.
  * Моделирование временной задержки сигнала и воздействия аддитивного белого гауссовского шума (AWGN) с заданным среднеквадратическим отклонением.
  * Реализация корреляционного приёмника, определение начала передаваемого пакета и восстановление временной синхронизации.
  * Реализация порогового приёмника на основе накопления отсчётов каждого символа и принятия решения о значении переданного бита.
  * Оценка количества битовых ошибок и расчёт коэффициента битовых ошибок (BER).
  * Удаление синхропоследовательности, проверка целостности принятого пакета с помощью CRC и восстановление исходного текстового сообщения посредством ASCII-декодирования.
  * Реализация прямого дискретного преобразования Фурье (ДПФ) без использования готовых алгоритмов FFT.
  * Построение и сравнение амплитудных спектров переданного и принятого зашумлённого сигналов.
  * Исследование влияния длительности символа на битовую скорость, ширину главного лепестка спектральной огибающей и частотное разрешение.
  * Визуализация основных этапов формирования, передачи, приёма и спектрального анализа цифрового сигнала.
