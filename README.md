# Основы сетей мобильной связи (MCN)

Репозиторий содержит лабораторные и практические работы по дисциплине **«Основы сетей мобильной связи»**.

## Стек технологий и инструменты
Для выполнения работ может использоваться любой из следующих инструментов:
* **Python** (библиотеки `SciPy`, `NumPy`, `Matplotlib`)
* **MATLAB**
* **Audacity** (для анализа звуковых сигналов)

---

## Структура репозитория

Каждая работа находится в соответствующей директории и включает в себя исходный код (скрипты) и файлы отчетов.

* `lab1/` — **Лабораторная работа №1: Временная и частотная формы сигналов. Преобразования Фурье. Дискретизация сигналов**
  * Исследование непрерывных и дискретных сигналов.
  * Применение прямого (ППФ/FFT) и обратного (ОПФ/IFFT) преобразования Фурье.
  * Проверка теоремы Котельникова (Найквиста) и изучение эффекта наложения спектров (aliasing).
  * Анализ спектра голосового сигнала (работа с `.wav` файлами и функцией `downsample`).
  * Квантование по уровню и оценка средней ошибки квантования для различной разрядности АЦП (3/4/5/6 бит).
